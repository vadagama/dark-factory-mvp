# ADR-013: Plane Tracker behind TrackerPort

- **Статус**: принято
- **Дата**: 2026-09-13
- **Автор**: software-architect
- Решение согласовано пользователем (ответы на вопросы раздела 5 plan.md, 2026-09-13)
- **Уточнено** (2026-09-13, архитектурное ревью ADR-пакета): защита webhook от replay и ротация секрета (п.6)

## Контекст

- Q-12 plan §5: Plane (self-hosted, webhook+HMAC) против Linear (SaaS); Jira-наследие dmtools — только источник паттернов, отвергнут как целевой трекер.
- Влияние: intake-контур и webhook-интеграции (T-033); блокирует полный intake, но не P0-ядро (CLI-интейк).

## Решение

1. Трекер пилота — **Plane, self-hosted**; интеграция через **webhook + HMAC**.
2. Доступ — строго через `TrackerPort` (T-005): get_change / publish_status / request_approval; webhook — ускоритель, не единственный журнал; состояние перед действием перечитывается (согласовано с ADR-006).
3. Адаптер Plane — **connector-плагин** (ADR-008); другие трекеры (Linear и др.) подключаются новыми адаптерами того же порта без изменения Flow.
4. Self-hosted Plane добавляет PostgreSQL — учтено в ADR-004: БД фабрики и БД Plane — логически разделённые инстансы.
5. До готовности адаптера — NoOp-заглушка `TrackerPort` (T-033).
6. **Защита webhook**: HMAC-подпись + signed timestamp в допустимом окне; дедупликация по event ID; constant-time сравнение подписи; ротация секрета с двумя активными ключами. Негативные тесты (invalid signature, replay, stale timestamp) — в T-033; webhook остаётся ускорителем, не источником истины (п.2, ADR-016 п.8).

Связанные задачи: T-033, T-005.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему не выбран |
|---|---|---|---|
| Plane (self-hosted, webhook+HMAC) | Данные внутри контура; рекомендован большинством исходных материалов | Self-hosting-нагрузка: +сервис и его БД | Выбрано |
| Linear (SaaS) | Нулевая эксплуатация, зрелый API | Данные вовне контура; нет self-hosted webhook+HMAC | Отклонено |
| Jira (наследие dmtools) | Существующие процессы | Тяжеловесен; отвергнут источниками как целевой трекер | Отклонено: только источник паттернов |

## Последствия

**Позитивные**
- Intake из трекера и публикация статусов/ссылок обратно; контур остаётся полностью self-hosted.
- Замена трекера изолирована `TrackerPort`.

**Негативные / риски**
- +сервис в K8s и его PostgreSQL — учесть в ресурсном профиле (ADR-010).
- Версионный drift Plane API — изолируется адаптером и contract-тестами (T-005).
